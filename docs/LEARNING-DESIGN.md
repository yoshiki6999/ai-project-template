# 教学法设计说明（Learning Design）

> 这份文档说明每个功能背后的学习科学依据，以及参考了哪些顶级语言学习 App 的做法、又在哪里做了升级。

## 1. 内容结构：583张卡 = 16个生活场景 × (29词汇 + 6–8语法)

| # | 场景 | # | 场景 |
|---|------|---|------|
| 1 | 🏪 便利店·超市 | 9 | 🤝 寒暄·人际 |
| 2 | 🍜 餐厅·外食 | 10 | 🛍️ 购物·退换 |
| 3 | 🚃 电车·交通 | 11 | 🌦️ 天气·防灾 |
| 4 | 🏠 租房·居家 | 12 | 📱 手机·网络 |
| 5 | 🏛️ 区役所·手续 | 13 | 💭 情绪·心理 |
| 6 | 🏥 医院·药局 | 14 | 📅 时间·预约 |
| 7 | 🏦 银行·邮局·快递 | 15 | 🗾 旅行·休闲 |
| 8 | 💼 职场·打工 | 16 | 🎓 学习·表达 |

- **难度标注要诚实**：N3 392张、N4 131张、N2 58张、N5 2张。JLPT 从2010年改革后不再公布官方词表，这里的等级参考常见的非官方词表。在日生活必需、但常见词表里归为 N2 的词（比如 避難、処方箋、在留カード），保留并照实标为 N2。
- **每张卡由浅到深分层**（"多维立体叠加、便捷收放"）：
  1. 第一眼看到：表情图 + 单词（带注音）+ 发音 + 意思
  2. 情境：带注音的例句 + 朗读 + 中文（中文先模糊处理，点一下才显示，逼自己先理解）
  3. 生活用法·文化：谁在什么时候说、对方通常怎么回、日本人的心理和习惯
  4. 搭配、易混辨析、**中文母语者陷阱**（中日同形异义，比如 怪我＝受伤，不是“怪我”）、记忆钩子
  5. 按需展开的 AI 深挖、AI 造句批改
- 详情页里每个部分都能折叠和展开，App 会记住你习惯展开哪些部分。

## 2. 学习方法 → 功能对照

| 学习科学原理 | 在本App里的实现 |
|-------------|----------------|
| **间隔重复**（FSRS-5，Anki 23.10 之后采用的开源算法） | `public/js/fsrs.js`：按“记忆稳定度、难度、当前还记得的概率”给每张卡排复习时间，目标记忆率可以设成 85%/90%/95% |
| **提取练习**（测试效应） | 新卡学完立刻小测；复习一律是“先回想，再看答案” |
| **期望难度 / 提取阶梯** | 记得越牢，题型越难：看词选意思 → 听音选意思 → 例句填空 → 看意思想日语（可以开口说）→ 只听句子理解（练N3听解） |
| **隐式评分** | 系统根据答对没有、用了多少秒自动判断“忘了/模糊/记得/秒答”，不用自己打分；只有“看意思想日语”这种题型需要自评 |
| **连续再学**（successive relearning） | 答错的卡几步之后用更简单的题型再出一次 |
| **双重编码 / 多感官** | 表情图 + 文字 + 发音 + 注音同时出现；“听音”题型只给声音 |
| **交错练习** | 复习时把不同场景的卡打乱混在一起；新卡每批3张，学完立刻混在一起测 |
| **生成效应 / 输出假说**（Swain） | 跟读（语音识别核对）、用目标词造句并由AI批改 |
| **可理解输入 i+1**（Krashen） | 例句除目标词外只用 N5–N4 词汇，平均15.6个字；“今日小剧场”用当天学过的词编故事 |
| **任务型教学 TBLT** | 情景实战：AI 扮演店员、医生、房产中介等16种角色，你要完成3个真实任务（比如“要不要袋子”“怎么付款”），完成一项就打勾 |
| **纠正性反馈 / 重述（recast）** | 对话中每句话都有“老师点评”和“更自然的说法”，还附上下一句可以怎么说的提示（脚手架） |
| **微学习 / 习惯养成** | 每天约5–8分钟；“1分钟碎片复习”；连续学习天数、经验值（XP）、今日进度环 |
| **随时随地** | PWA 离线可用；“地铁模式”（不自动发音、不要求开口） |

## 3. 参考的顶级 App 与本App的升级点

| 参考产品 | 借鉴的点 | 本App的升级 |
|----------|----------|-------------|
| Anki | 间隔重复 | 用最新的 FSRS-5 算法 + 隐式评分，卡片不用自己做，学习者不用自己评分 |
| Duolingo | 小步学习、连续天数、XP、路径地图 | 路径是“在日生活地图”，每一站对应一个真实生活场景 |
| WaniKani / Bunpro | 学习阶段（SRS stage）、语法填空 | 题型难度跟着记忆稳定度自动升级 |
| Speak / Praktika | AI 口语角色扮演 | 每个场景有明确的任务清单，AI 自动判断你完成了几项，并实时纠错 |
| Babbel / Busuu | 对话式、贴近生活 | 每张卡的“生活用法”写的是在日生活的真实细节（比如店员会问什么、该怎么回） |
| Memrise | 真实语境、记忆钩子 | 记忆钩子从中文母语者的角度写；专门提醒中日同形异义 |
| Drops | 5分钟、视觉化 | 表情图做视觉锚点，配合“1分钟碎片复习” |
| Pimsleur | 先听后说、渐进间隔 | 加入“听音选意思”“听句子理解”题型，加上跟读核对 |

## 4. AI 用在哪里（Claude）

1. **深挖讲解**：回答关于这张卡的任何问题，另给3个不同场景的例句、日本人的真实语感、汉字拆解
2. **造句批改**：0–100分，先肯定优点再指出问题，并给出更自然的说法
3. **情景实战**：角色扮演 + 任务完成判断 + 纠错 + 下一句提示
4. **今日小剧场**：用当天学的词编一个关西生活小故事，附一道理解题

所有 AI 输出都用 JSON schema 约束格式，日语一律带 `{漢字|かな}` 注音标记，前端统一显示成注音。

## 5. 以后可以做的升级
- 用高质量神经网络语音（TTS）替代浏览器自带的朗读声音（需要额外的服务密钥）
- 用户账号 + 云端同步进度（需要数据库）
- 根据每位学习者的复习记录，单独优化 FSRS 参数
- 扩展到 N2（同样的结构：场景 → 卡片）
